# Вектор

Мини-приложение: персональный путь развития сотрудника.

Сотрудник выбирает текущую и целевую роль. Приложение показывает пробелы в навыках и план: курсы, задачи, наставник. Для HR есть карта прогресса команды.

Рабочий прототип — один файл `vektor.html`. Node.js, npm и сборка не нужны.

## Как запустить

1. Скачайте репозиторий или только файл `vektor.html`.
2. Откройте `vektor.html` двойным щелчком. Подойдёт Chrome, Firefox, Edge или Safari.

Либо из папки репозитория:

```bash
git clone https://github.com/kowa-cpu/vektor.git
cd vektor
python3 -m http.server 8080
```

Затем откройте http://localhost:8080/vektor.html

Имя, выбранные роли и отмеченные шаги сохраняются в браузере.
